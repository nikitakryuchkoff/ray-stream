# Независимая регрессия Taste Controls

Результат: **статическая проверка пройдена; независимый браузерный прогон в этом субагенте недоступен**. Подтверждённых дефектов в проверенных изменениях не обнаружено. Это узкая регрессия контролов, а не повторный аудит всех 214 моделей.

Проверены действующие `src/main.tsx`, Layout, CatalogPage, ProductPage, ContactPage, маршрутизация, hooks формы/появления результатов и каскад globals → materials → typography → controls → navigation. Просмотренная сборка: `index-BTtsSpO8.js`, `index-CLwcU4c4.css`.

| Область | Независимый результат |
| --- | --- |
| Главная → каталог → категория → модель → обращение | Реальные `href` и существующая History API логика сохранены. Вложенные декоративные `span` не мешают обработке `closest('a[href]')`. |
| Поиск, empty/clear, Show more | Обработчики и область поиска сохранены; clear возвращает фокус в input и лимит 36; Show more прибавляет 36. Обёртки анимации имеют ключ модели и не заменяют ссылку карточки. |
| История | Query и limit сохраняются в `history.state`; категории имеют отдельные ключи страниц. |
| Галерея и раскрытие | Нативные кнопки, `aria-pressed`, `aria-expanded` и `aria-controls` сохранены. ChevronUp/Down переключается в React; повторного CSS-поворота disclosure нет. |
| Выбранная модель | ContactPage получает модель, hook добавляет её в JSON; mailto сохраняет название. Общая Unicode-очистка по-прежнему применяется. |
| Валидация | Required/min/max, ошибки и фокус первого неверного поля сохранены. |
| Loading | На форме и submit есть `aria-busy`; inputs и submit отключаются. `.button.loading:disabled` задаёт opacity 1 и имеет нужную специфичность/порядок каскада. Spinner декоративный; текст статуса доступен отдельно. |
| Размер submit | CSS задаёт ширину 224px на desktop и 100% на mobile независимо от idle/sending/retry. Фактическую геометрию и отсутствие изменения высоты должен подтвердить браузерный прогон. |
| Success/error/retry | Только HTTP 2xx + JSON + `{ok:true}` очищает поля. Ошибка сохраняет значения и модель, показывает retry и явный mailto fallback. |
| Accessibility fallback | Видимый focus, минимум размеров контролов, reduced motion, contrast/transparency и forced-colors предусмотрены в CSS; фактические computed styles в этом прогоне не измерялись. |

Дополнительно выполнены существующие `npm run check:contact` и `npm run check:model`: **PASS**. Контактный тест использует заглушку провайдера и проверяет методы, JSON, валидацию, модель, конфигурацию, получателя, acceptance и отказ. Ни одного реального письма не отправлено.

## Ограничение браузера

В этом субагенте CUA вернул пустой инвентарь (`apps: [], browsers: []`). Создание собственной вкладки через `iab` и ранее выбранный browser `2`, включая одну повторную попытку после подтверждения root, завершилось `Browser is not available`. Root сообщил, что его собственное подключение работает, и взял фактические браузерные сценарии на себя. Результаты root не выдаются здесь за независимые наблюдения субагента.

Поэтому клики, вычисленные opacity/width, aria-busy в реальном DOM, retained inputs, retry и success с перехватом POST **не заявлены как выполненные этим субагентом**. Для итоговой приёмки root отдельно проверяет home/catalog/search/model/contact и симулирует отказ/успех формы через CDP без настоящей доставки.

Исходники формы и сервера не менялись. Ни одна QA-вкладка не была создана; пользовательские вкладки, viewport, device/media overrides не затрагивались. Перехват сети не включался. Detector не запускался. Доставка почты и размещение остаются отдельными проверками окружения.
